# Tortex OTT — GitHub Root Logo Version

Upload these files directly to the GitHub repository root:

- `index.html`
- `style.css`
- `script.js`
- `tortex-logo.png`
- `admin/`

No `assets` folder is required.

The public site loads the logo from `./tortex-logo.png`.
The admin page loads it from `../tortex-logo.png`.

Admin demo login:
- Username: `admin`
- Password: `admin123`

This is a frontend/demo starter. A production OTT still needs a real backend, authentication, database, payments, secure video delivery/CDN, DRM where required, and licensed content.
