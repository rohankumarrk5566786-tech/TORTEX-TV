# TORTEX TV

Netflix-style streaming UI starter built with plain HTML, CSS and JavaScript.

## GitHub Pages
1. Upload all files to your GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose `main` and `/ (root)`.
5. Save and open the generated Pages URL.

## Included
Home, Movies, Series, Search, Details, Watch, My List, Login, Sign Up, Profile, Settings, History, About, Contact, Privacy, Terms and 404.

The project is responsive for mobile, desktop and large TV screens.

**Important:** The demo uses placeholder artwork/data. Only use movies, shows, posters, trailers and video streams that you have the rights/licences to distribute.
